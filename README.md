# Бот для отношений 💌

Telegram-бот для пар: вишлист, отложенные сюрпризы, идеи свиданий и напоминания о важных датах.

## Возможности

- **WishList** — добавляйте желания (текст или фото), смотрите список партнёра и свой, удаляйте записи
- **Unexpected Surprise** — отправьте партнёру сообщение, которое бот доставит в случайный момент в заданном диапазоне (дни, часы или месяцы)
- **This Month's Date** — 15-го числа каждого месяца одному из партнёров назначается идея свидания; организатор чередуется
- **An Important Date** — сохраняйте важные даты (годовщины, праздники) и получайте напоминания заранее

## Команды

| Команда   | Описание                                      |
|-----------|-----------------------------------------------|
| `/start`  | Запуск бота и главное меню                    |
| `/myid`   | Показать ваш Telegram ID                      |
| `/pair ID`| Связать аккаунт с партнёром по его Telegram ID |

## Стек

- Python 3.12
- [aiogram](https://docs.aiogram.dev/) 3.x — Telegram Bot API
- [asyncpg](https://magicstack.github.io/asyncpg/) — PostgreSQL
- [aiohttp](https://docs.aiohttp.org/) — HTTP-сервер для health-check

## Локальный запуск

### 1. Клонирование и зависимости

```bash
cd pythonProject
python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Переменные окружения

Создайте файл `.env` или задайте переменные в системе:

| Переменная       | Описание                                      |
|------------------|-----------------------------------------------|
| `BOT_TOKEN`      | Токен бота от [@BotFather](https://t.me/BotFather) |
| `DATABASE_URL`   | Строка подключения к PostgreSQL, например `postgresql://user:password@localhost:5432/dbname` |

### 3. Запуск

```bash
python bot.py
```

При первом запуске бот автоматически создаст необходимые таблицы в базе данных.

## Деплой на Render

Проект рассчитан на хостинг [Render](https://render.com/):

- `runtime.txt` задаёт версию Python
- HTTP-сервер на `/` и `/health` нужен для проверки работоспособности
- Переменная `RENDER_EXTERNAL_URL` используется для периодического «пробуждения» приложения (free tier)
- Порт задаётся через переменную `PORT` (по умолчанию `10000`)

## Как начать пользоваться

1. Оба партнёра запускают бота командой `/start`
2. Каждый узнаёт свой ID через `/myid`
3. Один из партнёров связывает аккаунты: `/pair <ID_партнёра>`
4. Дальше доступны все функции из главного меню
